Developer Documentation & Quickstart

Apex Cloud & Gear streams real-time customer behavior directly to our Confluent Cloud Apache Kafka backend. By analyzing event timestamps, dwell duration, and drop-off patterns in tumbling 30-second windows, our platform identifies and rescues at-risk customer sessions before abandonment.

1. Embedding the CustomerPulse Client SDK

Insert this single-line tag before the closing </head> tag on any website:

<script src="http://localhost:3000/tracker.js" data-site-id="apex_store"></script>

2. Capturing High-Friction Events

Trigger custom telemetry when users experience friction during checkout:

// Fired when customer pauses or leaves during credit card submission
CustomerPulse.track('checkout_abandon', {
  cartValue: 1999,
  abandonStep: 'payment_auth_pending',
  regionid: 'Region_1'
});

3. Ingestion Pipeline Schema (Apache Avro)

All raw pageviews conform to the registered schema contract:

{
  "type": "record",
  "name": "PageviewRecord",
  "fields": [
    { "name": "userid", "type": "string" },
    { "name": "pageid", "type": "string" },
    { "name": "viewtime", "type": "long" },
    { "name": "regionid", "type": "string" }
  ]
}
